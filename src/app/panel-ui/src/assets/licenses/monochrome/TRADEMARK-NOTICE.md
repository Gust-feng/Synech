# 商标与品牌资产说明（TRADEMARK NOTICE）

本图标包中的绝大多数图形为各公司／产品的**注册商标或品牌资产**，
其著作权与商标权归各自权利人所有。`manifest.csv` 中「许可证」一列标注为
「官方品牌资产，未声明公开许可」「无开放许可（官方商标资产）」等字样的条目，
表示权利人未公开发布可自由使用的授权条款——本包收录这些图形**仅用于在软件界面中
准确指代对应品牌／服务**（nominative use），不构成权利转让，也不暗示任何代言、
赞助或关联关系。

使用要求（除非权利人品牌指南另有说明）：

- 不得将图标作为自有品牌使用，不得暗示与权利人的关联、代言或赞助；
- 不得对图形做歪曲性修改（本包的 currentColor 单色化为界面主题适配所需的中性处理，
  未改变图形的基本识别特征；另见 manifest.csv「几何修改」列）；
- 具体品牌的展示规范以各权利人官方 brand guidelines 为准。

各条目的原始来源见 `manifest.csv` 的「素材来源／来源URL」列。
