# 模型服务接入范围

本文说明产品接入边界，不维护模型定义表。服务和模型事实以当前安装的
`@earendil-works/pi-ai` 为准；图标只提供视觉标识。连接与目录决策见 ADR 0008。

## 当前范围

2026-09-30 核对 Pi 0.87.1：41 个原生文本服务 provider 均有独立服务方案，
真实模型覆盖 10 种 API。官方方案复用原生 provider，不再只套三种通用 transport。
这表示配置与运行适配范围，不表示已逐家完成真实账号请求验收。

添加服务先提供直接的自定义入口，官方目录按品牌/平台分组后选择区域、Coding、
Token Plan、API、云服务或订阅方案。每个已添加连接独立保存密钥、模型和参数，
同方案可创建多个连接；已有核心品牌槽位保持原身份，不自动合并旧配置。
Pi 的内部 provider 标识由预设携带，不作为用户设置项。

自定义服务继续支持 Chat Completions、Responses、Anthropic Messages，直接填写
地址和模型名；远程目录发现只保存模型 ID，不猜能力。原生目录使用 Pi 的
可用模型过滤与刷新，不硬要求 API Key 或 `/models`。未确认模型不伪造能力；
原生运行只能使用该 provider 的真实模型目录。

Pi 缺少统一 provider 地址时保留原生模型专属地址或云定位参数，不拿 OpenAI 地址
填空，也不把一个网关默认地址强盖到该网关的所有模型上。

## 原先缺少的十个服务

| 服务 | 原生接入方式 |
| --- | --- |
| Google / Gemini | Gemini 原生 API 与 API Key |
| Google Vertex AI | 原生 API；API Key 或本机 ADC/服务账号，项目与区域参数 |
| Azure OpenAI | 原生 Responses，资源地址、部署与 API 版本 |
| Amazon Bedrock | Converse Stream；Bearer Key 或本机 AWS 凭据，区域/profile |
| Mistral | 原生 Conversations 与 API Key |
| OpenAI Codex | ChatGPT 订阅 OAuth，Pi 登录与刷新 |
| Radius | 原生 Messages，API Key/OAuth 与动态目录刷新 |
| Cloudflare AI Gateway | 账号与网关身份，Pi 端点和网关鉴权处理 |
| Cloudflare Workers AI | 账号身份与 Pi 原生请求处理 |
| GitHub Copilot | Pi 登录、订阅模型过滤与专用请求处理 |

其它支持 OAuth 的原生 provider 同样复用 Pi 已声明的登录方式，不维护第二套
登录引擎。账号是否拥有对应模型、网络和地区是否可用，需要真实连接验收。

登录文本步骤允许提交空值，由原生 provider 判断默认值与有效性；GitHub Copilot
的企业域名留空即使用 github.com，验证码和密钥输入仍要求非空。桌面宿主收到
授权地址或设备授权地址时，复用系统浏览器打开能力，每次登录同一地址只自动
打开一次；取消后的迟到通知不得打开网页。仅允许无内嵌凭据的 HTTP(S) 地址，
浏览器打开失败不改变登录终态，保留手动授权链接；浏览器版 Panel 使用手动链接。

## 图标与额外品牌

Arcee、AionLabs、StepFun、LongCat、IBM Granite、Liquid、KAT 等图标不意味着
Pi 当前提供了对应的独立直连 provider。它们仍可作为模型家族标识；不能仅凭图标
新增一个虚构地址或协议的服务。没有 Pi 原生声明的端点走显式自定义服务，不猜能力。

图标来源和选用规则见 Panel assets 的 README；已有彩色版本优先，真正的黑白
标识保持主题适配，不把过时的彩色图案当成当前品牌标识。
